# 应用 UI 设计指南（应用为主体，无 AI 味）

目标：交付的页面要像**一个认真做过的产品**，而不是「AI 生成的 demo」。
本技能的应用界面**完全由应用自己实现**（原生 HTML/CSS/JS 即可），不是 `plugin-ui.json` 的工具卡。写前端之前先按本篇定 tokens 与设计语言卡，写完逐条过「无 AI 味清单」。

## 1. Design tokens（先定，再写 HTML）

全部用 CSS 变量集中管理，禁止散落的十六进制色值。

| 类别 | token | 取值建议 | 说明 |
| --- | --- | --- | --- |
| 底色 | `--bg` | 暖白 `#f7f5ef` / 冷灰 `#f4f6f8` | **不用纯白 `#fff`**，纯白是 demo 味的第一信号 |
| 卡片 | `--card` | `#fffdf8` / 白色叠加 96% | 与底色有 2~4% 明度差 |
| 正文 | `--ink` | 深墨绿 `#22302f` / 炭黑 `#1f2328` | 不用纯黑 |
| 次要 | `--muted` | `#71807b` / `#6b7280` | 标签、说明 |
| 主色 | `--primary` | 按领域选（见 1.1） | 按钮、选中态、AI 浮钮 |
| 强调 | `--accent` | 与主色同族高饱和 | 仅角标/徽标，占比 <10% |
| 分隔 | `--line` | `rgba(<ink>, .09)` | 1px 细线，别用灰框 |
| 阴影 | `--shadow` | `0 22px 60px rgba(46,74,68,.12)` | 大而柔，多层 |
| 圆角 | `--r-sm/md/lg/pill` | `12 / 20 / 28 / 999px` | 大圆角是产品感的关键 |
| 字体 | `--font` | 系统栈 + `PingFang SC` / `Microsoft YaHei` | 中英文都要覆盖 |
| 间距 | `--s-1..6` | 4/8/12/16/24/32 | 8 的倍数 |
| 动效 | `--ease` | `cubic-bezier(.22,.61,.36,1)` | 统一 0.25s |

```css
:root {
  --bg: #f6f4ee; --card: #fffdf8; --ink: #22302f; --muted: #71807b;
  --primary: #0e847a; --accent: #f4693d; --line: rgba(34,48,47,.09);
  --shadow: 0 22px 60px rgba(46,74,68,.12);
  --r-sm: 12px; --r-md: 20px; --r-lg: 28px; --r-pill: 999px;
  --font: -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif;
  --ease: cubic-bezier(.22,.61,.36,1);
}
```

### 1.1 按领域选主色（避免默认蓝紫）

| 领域 | 主色 / 强调 | 材质与母题 |
| --- | --- | --- |
| 数据/运维平台 | 石墨 `#23272e` + 信号三色 | 深色顶栏 + 浅灰工作区；状态灯圆点、等宽数字 |
| 金融/账务 | 深墨绿 `#0c3d33` + 香槟金 | 米白纸感；数字用上下细线的「账本行」 |
| 商城/零售 | 暖橘 `#e8632c` + 深可可 | 奶油底 + 促销斜纹；价格签缺角卡 |
| 医疗/健康 | 薄荷绿 `#2fa48d` + 云白蓝 | 大留白 + 柔光晕；体征曲线面积图 |
| 教育/内容 | 青绿 `#0e847a` + 暖橙 | 便签色块拼贴；进度徽章 |
| 出行/物流 | 藏青 `#1c2b4a` + 荧光橙 | 冷灰蓝 + 轨迹点线；进度条节点 |
| 文旅/生活 | 陶土 `#b96a4b` + 暖灰绿 | 手作纸感颗粒；打卡圆点 |
| 研发协作 | 墨蓝 `#26364f` + 松石绿 | 网格纸底 + 时间线；评审状态标签 |

主色只承担「品牌与主行动」，辅助信息一律用中性色阶——颜色越多越像模板。

## 2. 设计语言卡（写码前必须产出，随 README 交付）

```text
领域板块：<如 数据运维平台>
主色 / 强调色：<如 石墨 #23272e / 信号橙 #ff8a3d>
背景材质：<如 浅灰工作区 + 细网格底纹>
形状语言：<如 直角偏多 8px 圆角、卡片左侧状态色条>
标志性元素：<如 顶栏右侧的「系统状态灯组」+ 指标卡的等宽大数字>
气质关键词：<3 个，如 冷静 / 高密度 / 可追溯>
与邻近案例的差异：<辅助色 X / 材质 X / 布局 X / 母题 X —— 至少两项不同>
```

硬要求：
1. **同类不撞脸**：同板块两个应用，辅助色、材质、布局、母题至少两项不同；
2. **标志性元素必须贯穿**：hero、卡片、空态里都能看到（不是只换个主色）；
3. **AI 面板跟随本应用**：浮钮、气泡、思考动画用本应用主色，不许所有应用共用一套；
4. **3 秒验收**：打开页面 3 秒说不出「这是哪类产品」→ 重做配色与母题。

## 3. 布局模板（顶栏 + 主区 + AI 侧栏）

```text
┌───────────────────────────────────────────────────────────┐
│ 顶栏：品牌名 · 全局搜索/筛选 · 数据时间范围 · 状态 · 头像    │  sticky + 毛玻璃
├───────────────────────────────┬───────────────────────────┤
│ 主区（按形态选一种）           │  AI 助手侧栏（380px）      │
│  A 看板型：统计卡行 → 图表 →  │  · 头部：助手名 + 清空     │
│    明细表格                     │  · 消息区（默认一条欢迎）  │
│  B 列表详情型：筛选栏 → 卡片   │  · 工具轨迹（折叠）        │
│    网格/表格 → 右侧详情抽屉     │  · 示例问题胶囊            │
│  C 工作台型：左树/列表 +        │  · 输入框 + 发送/停止      │
│    右工作区（编辑器/表单）      │                           │
└───────────────────────────────┴───────────────────────────┘
```

- 顶栏 `position: sticky; backdrop-filter: blur(20px)`，高度 56~64px；
- 主区宽度自适应：`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`；
- AI 侧栏默认收起为右下角浮动按钮，展开时**不遮挡主区关键操作**（`max-width: 380px`，小屏改全屏抽屉）；
- hero（若需要）：大标题 `clamp(28px, 4vw, 44px)` + 一个彩色强调词 + 一行副标 + 一个主行动按钮，别堆「三大特性」。

## 4. 组件细则

| 组件 | 要求 |
| --- | --- |
| 卡片 | 大圆角 + 大柔阴影；hover `translateY(-4px)` + 阴影加深，0.25s 过渡 |
| 表格 | 不要裸表格：卡片包裹、表头浅底、行 hover 高亮、数字右对齐、状态用标签色 |
| 标签/徽标 | 圆角 pill，状态色成组（成功/进行中/失败/待处理），不要用 emoji 代替 |
| 按钮 | 主按钮品牌色渐变 + 彩色投影；次要按钮描边；全部有 hover/active/disabled |
| 输入 | label 常显（不拿 placeholder 当 label）；聚焦主色描边；错误内联红字 |
| 弹层/抽屉 | 关闭按钮 + 遮罩点击 + Esc 三种关闭；提交成功自动关；全局 `[hidden]{display:none!important}` |
| 加载 | 列表用骨架屏（灰块 + shimmer），按钮 loading 态禁用防重复提交 |
| Toast | 右上角滑入，2.5s 自动消失；成功/失败不同色；**不用 alert()** |
| 图标 | 内联 SVG（1.5~2px stroke、`currentColor`），**不用 emoji** |

## 5. 空态、错误态、边界态

| 态 | 写法 |
| --- | --- |
| 空列表 | 一句人话 + 一个行动按钮：`还没有巡检记录，去创建第一条巡检`，不是「暂无数据」 |
| 首次进入 | 用 1~2 行说明「这里能做什么」+ 一个示例入口，不要空白大屏 |
| 加载失败 | 说明原因（网络/服务未启动）+「重试」按钮，保留已加载内容 |
| 数据为 0 | 显示真实 `0` 与口径（如「本月 0 笔」），不要伪造曲线 |
| AI 不可用 | 面板内提示「AI 服务未就绪，请检查底座与模型配置」，主界面业务功能照常可用 |
| 无权限/未配置 | 指向具体设置项（如「设置 → 模型」），不要只说失败 |

## 6. 响应式

- 断点：`≤480px` 单列；`481~1024px` 双列；`>1024px` 主区 + AI 侧栏；
- 字号用 `clamp()`，表格在窄屏改卡片列表或横向滚动容器（`overflow-x:auto`）；
- AI 面板窄屏 `width:100%; height:100%`，关闭按钮固定在右上；
- 375px 宽必须无横向滚动、导航可用、按钮可点（触控目标 ≥40px）。

## 7. 可访问性（低成本高收益）

- 所有可交互元素是 `<button>`/`<a>`，不是可点击的 `<div>`；
- 图标按钮有 `aria-label`；弹层有 `role="dialog"`、`aria-modal="true"`，打开时焦点进面板、Esc 关闭、关闭后焦点回触发按钮；
- 表单 `label for` 与输入 `id` 对应；错误用 `aria-live="polite"`；
- 对比度：正文对底色 ≥ 4.5:1；状态不只靠颜色（配文字/图标）；
- 键盘可达：Tab 顺序符合视觉顺序；焦点样式可见（`outline` 或主色 ring）防 `outline:none`。

## 8. 无 AI 味清单（出现任一即重做）

| 信号 | 正确做法 |
| --- | --- |
| 默认蓝紫渐变 `#6366f1/#8b5cf6`、`135deg` 大渐变铺满首屏 | 按领域定主色；渐变只用于主按钮/品牌标 |
| 纯白底 + 居中一列卡片 | 有层次背景（径向光斑 + 细点阵/网格/纸感）+ 非对称布局 |
| 所有圆角 8px、所有阴影 `0 2px 4px` | 大圆角 20~28px、多层大柔阴影 |
| emoji 当图标（🛒 🚀 ✨） | 内联 SVG 线性图标 |
| 表格裸奔、直角灰框 | 卡片化数据 + 状态标签 + 斑马纹/hover |
| Lorem ipsum / 英文占位 / 「示例数据」 | 真实中文业务文案（品牌名、编号、具体日期） |
| 三等分「为什么选我们」特性卡 | 真实业务区块：看板/列表/详情/表单/状态流 |
| 按钮无 hover、无过渡、无 loading | 全部交互有过渡与加载态 |
| `alert()` 提示 | Toast |
| 所有应用同一套配色/卡片/母题 | 每类场景一套设计语言卡，标志性元素贯穿 |
